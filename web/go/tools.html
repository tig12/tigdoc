gofmt 
gofmt -w file.go    # overwrite file.go
gofmt -d file.go    # print the diff
gofmt -l *.go       # list the file names that differ
    -comments=true      # Print comments; if false, all comments are elided from the output.
    -tabs=true          # Indent with tabs; if false, spaces are used instead.
    -tabwidth=8         # Tab width in spaces.

gofmt [flags] [path ...]

The flags are:
    -d
    	Do not print reformatted sources to standard output.
    	If a file's formatting is different than gofmt's, print diffs
    	to standard output.
    -e
    	Print all (including spurious) errors.
    -l
    	Do not print reformatted sources to standard output.
    	If a file's formatting is different from gofmt's, print its name
    	to standard output.
    -r rule
    	Apply the rewrite rule to the source before reformatting.
    -s
    	Try to simplify code (after applying the rewrite rule, if any).
    -w
    	Do not print reformatted sources to standard output.
    	If a file's formatting is different from gofmt's, overwrite it
    	with gofmt's version. If an error occurred during overwriting,
    	the original file is restored from an automatic backup.

go get - go install

https://tip.golang.org/doc/go1.16#modules           use of go get to build and install packages is deprecated.

=== uninstall package ===
go clean -i github.com/test/package
go clean -i importpath...
(be sure to include ... on the importpath, because if a package includes an executable, go clean -i will only remove that and not archive files for subpackages)
or remove manually the code in $GOPATH/src and the package file under $GOPATH/pkg/

# install
go get -u github.com/kortschak/utter
# uninstall
go get -u github.com/kortschak/utter@none

go get golang.org/x/tools/cmd/goimports
goimports -w file.go

go mod

go mod init bdl.local/bdl
# the downloaded modules are cached locally (in $GOPATH/pkg/mod)

# if needed, add replace directive
replace bdl.local/bdl => ../src/

# go.mod contains the list of direct dependencies
# go.sum contains the expected cryptographic hashes of the content of specific module version
# go.mod and go.sum should be checked into version control

# synchronize the module's dependencies, adding those required by the code, but not yet tracked in the module. 
go mod tidy

# lists the current module and all its dependencies
go list -m all

# Change go version in go mod
go mod edit -go=1.22
