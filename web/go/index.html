Install go

wget -c https://go.dev/dl/go1.24.6.linux-amd64.tar.gz
sudo rm -rf /usr/local/go && sudo tar -C /usr/local -xzf go1.24.6.linux-amd64.tar.gz
go version

See ~/if/cheatsheets/ub*.txt for go env and .bashrc modifications

To update go:
go env -w GOTOOLCHAIN=go1.24.6+auto (go1.24.6 being the last version)
https://go.dev/doc/toolchain

/usr/local/go           # installation dir
/usr/local/go/bin/go    # binary location

# uninstall go
sudo rm -fr /usr/local/go
# then remove go from $PATH
