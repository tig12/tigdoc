Gansible

Go program used to deploy machines. Opinionated, not generic as Ansible.
Handles the following stack:
  • Linux and systemd for execution and monitoring
  • Posgresql and pgbackrest
  • Caddy
  • Podman

Install, usage

cd /path/to/gansible
go build
# ==> Generates executable gansible
To run the program: 
./gansible <host> <action> <argument>
  • <host>: machine to deploy - corresponds to an directory in conf/
  • <action>
  • <argument>

Configuration

Before using gansible: 
cp -r conf.dist/ conf
and adapt parameters. 
conf/
    ├── global.yml
    └── hdist
        ├── apps
        │   ├── myapp.yml
        │   ├── mypod.yml
        │   ├── secrets
        │   │   └── myapp.env
        │   └── site.fr.yml
        └── hdist.yml
  • conf/global.yml: configuration applied to all hosts by default - can be redefined in each host configuration
  • conf/hdist/: configuration of host call "hdist" (replace "hdist" by a name identifying your host).
  • conf/hdist/hdist.yml: configuration of host call "hdist" (replace "hdist" by a name identifying your host). 
./gansible htest init
./gansible htest system
./gansible htest postgresql init

# if "all" instead of "bdl" => all apps of this server
./gansible htest user bdl
./gansible htest db bdl
./gansible htest secret bdl
./gansible htest service bdl
